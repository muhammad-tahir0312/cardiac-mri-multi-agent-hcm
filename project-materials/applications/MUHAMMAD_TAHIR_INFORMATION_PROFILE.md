## 4. Research profile

### Current cardiac MRI research

Current source-of-truth title: `Multi-Agent System for Automated Cardiac MRI Analysis and Decision Support`.

The current repository describes a four-part workflow:

1. Cardiac MRI segmentation.
2. Quantification of ventricular volumes, ejection fraction, and myocardial mass.
3. Guideline-grounded clinical reporting using retrieval and language models.
4. Explainability and uncertainty analysis.

Current repository evidence includes:

- Python-based implementation.
- Cardiac MRI data loading and harmonisation across ACDC, M&Ms, and M&Ms-2.
- A verified manifest of 830 labelled subjects.
- Deep-learning segmentation using CineMA, with nnU-Net as a trainable comparison component.
- Deterministic measurement of EDV, ESV, LVEF, and myocardial mass.
- Retrieval from cardiovascular guidelines using FAISS and BM25.
- Explainability using segmentation-focused Grad-CAM and ensemble uncertainty.
- A typed LangGraph workflow with plausibility checks, bounded recomputation, refusal conditions, provenance, and fidelity checks.
- The repository status dated 13 July 2026 reports approximately 7,000 lines across 16 modules. A fresh fast-test run on 30 September 2026 produced 108 passed tests, 4 skipped tests, and 10 slow tests deselected. The application should not claim 122 currently passing tests.
- Some long segmentation, baseline, and language-model experiment runs were still incomplete in the latest status file.

Safe application description:

> I am developing a multi-agent cardiac MRI workflow that connects image segmentation, quantitative cardiac measurements, guideline-grounded reporting, and explainability. I have worked on data harmonisation across three public cardiac MRI datasets, implemented Python-based evaluation and safety checks, and tested the pipeline on a verified set of 830 labelled subjects. The work has strengthened my interest in scalable, patient-specific cardiovascular modelling while also showing me the importance of uncertainty, validation, and reproducibility.
