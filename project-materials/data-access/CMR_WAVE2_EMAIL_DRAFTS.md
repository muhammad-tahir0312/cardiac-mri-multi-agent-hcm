## Do not send from this file

- **HCHS:** published availability statements are not uniform. One HCHS paper says third-party sharing is barred for ethical/legal reasons and routes enquiries through `dm-hchs@uke.de`, while other project-specific papers describe reasonable-request access with HCHS permission. Keep this on hold unless Dr Uzair approves a low-probability Steering Committee enquiry.
- **ECCO-GEN:** the public EGA DAC currently controls a valve-tissue methylation dataset, not CMR images. Do not use the EGA request button for this project. A direct email to Yasmine Aguib should be only a routing enquiry if Dr Uzair approves it.
