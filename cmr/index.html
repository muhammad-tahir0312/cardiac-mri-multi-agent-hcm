Exactly two phases, ED and ES, as separate 3-D NIfTI files (.nii or .nii.gz) — this system does not auto-detect ED/ES from a full cine series. Ground truth is optional and only used for side-by-side comparison; it must already use the CANONICAL label order (1=LV, 2=Myo, 3=RV) — ACDC's own native order (1=RV, 3=LV) will be rejected, not silently remapped, the same guard every dataset loader in this codebase runs on load.

Pipeline — node by node, live

Segmentation ≈ 45s, one LLM report ≈ 40–80s (occasionally two calls if the model leaves diagnosis empty on the first try), Seg-Grad-CAM another ~1–2 min — a full run is a few minutes, not instant. This IS the pipeline, not a demo of it: the same cmr/graph.py state machine every batch run goes through.

    These settings apply to the next run you start on the Run tab, and that run will record them in its own run.json. They do not edit a finished run: the line in the header (vertical_slice_f66e47 · backend=… · gate=…) is read from that run's run.json — the reproducibility record of what actually happened — and is deliberately immutable.
